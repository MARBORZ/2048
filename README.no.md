# 2048

[English](README.md) · Norsk

Nettleserversjon av 2048 i vanilla JavaScript. Piltastene flytter brikkene på et 4×4-brett, like tall slås sammen. Målet er å få en 2048-brikke.

Ville øve på klasser og state uten rammeverk. Brettet ligger i `Grid`, `Cell` og `Tile` styrer posisjon og sammenslåing, `index.js` tar seg av input. Stiler i SCSS.

## Kjør

Åpne `index.html` i nettleseren.
