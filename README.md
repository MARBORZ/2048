# 2048

Browser version of 2048 in vanilla JavaScript. Arrow keys slide tiles on a 4×4 grid, same numbers merge. Goal is to get a 2048 tile.

Wanted to practice classes and state without frameworks. Board is in `Grid`, `Cell` and `Tile` handle position and merging, `index.js` handles input. Styles in SCSS.

## Run

Open `index.html` in a browser.
