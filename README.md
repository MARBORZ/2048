# 2048

The 2048 puzzle in plain JavaScript, no libraries. Arrow keys slide the tiles; equal tiles merge.

The code is split into small classes: `Grid` holds the 4x4 board, `Cell` and `Tile` handle position and merging, `index.js` wires up input and the game loop. Styles are written in SCSS and compiled to `css/`.

## Run

Open `index.html` in a browser. Nothing to install.
